Haptics

Haptics are part of the presets, not an add-on.

A preset names a pattern; when the cue starts, that pattern fires. The tap becomes something the player feels in their hand, not only sees.

Patterns are data

A HapticPattern is a list of segments. Each segment is a wait in milliseconds, then a buzz in milliseconds at an amplitude from 0 to 255. A pattern compiles to the alternating wait/buzz timing form with per-buzz amplitudes, amplitudes clamped to 0–255, and TotalMilliseconds summing delays plus durations.

The 12 built-in patterns

LightTap, MediumTap, HeavyHit, DoubleTap, Success, Failure, Pickup, Explosion, Heartbeat, MachineGun, CoinSparkle, AlarmBuzz.

Presets reference these by name — HitMedium carries MediumTap, the UI error preset carries Failure, the heartbeat preset carries Heartbeat, and so on. The full per-preset mapping is visible in each preset's data and in the haptics test bench in the home window (Editor Preview & Inspectors).

The facade in code

JuiceHaptics offers Play(string patternName), Play(HapticPattern), Stop(), an Enabled master switch, the active Backend, SetBackend(...) for a custom backend, FindBuiltIn(name), and BuiltInNames. Unknown pattern names are ignored without throwing. With the master switch off, no Play call reaches a backend — the switch is the player's off button, and every call respects it.

IHapticBackend is the extension point: implement it and set your own backend for custom devices.

What each platform does in this version — stated exactly

  • Android: the backend compiles the pattern to a waveform with per-segment amplitudes on devices that support them (API 26 and above). Below that it uses a timed vibrate, and on any failure it falls back to the system vibrate. A pattern is guarded so it does not throw into the game.
  • iOS: this version fires the platform's single system vibrate once per pattern. Per-pattern rhythm and amplitude are not available on iOS in this version.
  • Desktop and the Editor: silent. The no-op backend is active, so the haptics test bench in the Editor sends patterns without buzzing anything; judge patterns on a connected Android device.

That platform split is a shipped limit of this version, printed here and on the Honest Limits page in the same words.
