Honest Limits: What v1 Is Not

Honest limits, in writing, so nothing below surprises you after purchase.

  • Not a tween library. There is no general-purpose “animate any value over time” API and no tween chaining language. JuiceWorks Pro plays feedback presets built from seven feedback channels; if you need to tween a health bar to a value, that is a different tool's job.
  • Not 3D-first. The presets are tuned for 2D sprites, uGUI, and camera rigs. The transform channels work on 3D objects, but no preset ships tuned for 3D characters, and no claim is made about them.
  • iOS haptics are the system vibrate. Android plays waveform patterns with per-segment amplitudes. On iOS this version fires the platform's single system vibrate once per pattern — per-pattern amplitude and rhythm are not available there yet.
  • No physics impulses. “KickBack” and friends are visual feel — transform offsets shaped like knockback. JuiceWorks Pro never touches a Rigidbody velocity; your physics stays yours.
  • No audio. The package is silent by design in this version; pair presets with your own sound triggers. A preset's haptic name slot is for vibration, not sound.
  • No particles. Presets animate the target itself. There is no particle system, no trail renderer, and no shader effect in the box.
  • No TextMeshPro dependency. UI feedback targets uGUI Graphics, and the sample HUD uses plain uGUI Text.
  • No generated presets. Every built-in is authored data, tuned per effect.
  • No serialized demo scene. The Juice Arcade sample ships as scripts plus the guided scene build on the Sample Guide page. There is no ready-made scene file to open.
  • Editor preview is not Play Mode. Preview plays the real channels on the real target and restores it afterwards, but timing comes from the editor update loop — judge final feel in Play Mode or on a device.
  • Preset numbers are starting points. The built-ins are tuned against the sample's sprite scale (roughly 1-unit characters). Very large or very small targets may want amplitude and offset values scaled to match — that is what your own preset assets are for.
